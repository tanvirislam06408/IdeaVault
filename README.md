# 🚀 Features

- 🔐 JWT Authentication with Email/Password & Google Login
- 💡 Users can create, update, and delete startup ideas
- 💬 Interactive comment system with edit & delete functionality
- 🔎 Search ideas by title using MongoDB regex search
- 🎯 Filter ideas by category
- 🌙 Dark & Light theme toggle
- 📱 Fully responsive for mobile, tablet, and desktop
- 🔥 Trending ideas section on homepage
- 👤 User profile dropdown with profile management
- ⚡ Toast notifications for all CRUD operations
- 🛡️ Protected private routes with persistent login
- 🎨 Modern UI using HeroUI + Tailwind CSS

# 🌐 Environment Variables

## Client

```env
NEXT_PUBLIC_API_URL=your_api_url
NEXT_PUBLIC_AUTH_URL=your_auth_url
```

## Server

```env
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_jwt_secret
GOOGLE_CLIENT_ID=your_google_client_id
GOOGLE_CLIENT_SECRET=your_google_client_secret
```
